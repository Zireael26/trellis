# Recipe manifest

One row per recipe. Recipes are generic, parametric skeletons — specifics enter through `args`, never as baked literals. The capability and degrade columns echo the two-level graceful degrade in `SKILL.md`. The **Loop safety** column records each recipe's `meta.safety` declaration — every recipe is a loop and must honor the loop-safety contract (`core-rules/loop-safety.md`); **a recipe with no `safety` declaration is non-compliant** (flagged by `cross-project-process-audit`, a `process-gate` / review finding).

Every runnable recipe also preserves one settled receipt per declared identity and emits a structured `workflow_stage_gate` JSON log before consuming a stage. Null/throw is failure; valid negative or HOLD verdicts are successful receipts. Required stages require every expected identity. Only explicitly optional provider legs use `minSuccess: 0`; a provider fallback itself is required and fails the stage if it also returns null/throws. `filter(Boolean)` is never a stage-success policy.

Capability inputs are caller-resolved, not read from config inside recipes. Callers pass `loopSafety` where inherited safety values are consumed. Omission is a known safe degrade: stages without a declared `agentType` inherit the calling main loop exactly.

Canonical mutation recipes dispatch implementation work in waves of at most two by default and emit `workflow_checkpoint` after every successful wave. `args.maxParallel > 2` fails closed unless accompanied by non-empty `parallelJustification`, `args.runId`, an exact completed two-target `pilotReceipt` bound to the current recipe/run, the first two current target IDs and successes, the current task/scope fingerprint, and a positive recipe-local or caller-resolved safety budget. Duplicate expected IDs fail before mutation dispatch. Required receipt failure or identity loss prevents both the checkpoint and the next wave. Read-only triage/verification may retain a one-shot parallel barrier and does not claim mutation slots; `fanout-verify` teardown uses the same bounded waves with optional-settlement semantics.
